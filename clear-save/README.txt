타임 보칸 비공식 한글화 V1.0 — 클리어 세이브

한글화: 기타 깎는 노인

Bokan-KR.srm은 '매우 어려움' 클리어 플래그를 적용한 새턴 백업 RAM입니다.
Beetle Saturn에서 스테이지 선택 메뉴 표시와 L/R 변경을 확인했습니다.
스테이트(.state)가 아니며, 일반 게임 진행 기록과 옵션을 포함합니다.

게임이 너무 어려우면:
  1. RetroArch를 완전히 종료합니다.
  2. 현재 사용 중인 Bokan-KR.srm을 다른 이름이나 폴더에 백업합니다.
  3. 이 파일을 RetroArch의 저장 파일 폴더에 복사합니다.
     코어별 저장을 사용한다면 보통 saves/Beetle Saturn/Bokan-KR.srm입니다.
     실제 경로는 RetroArch '설정 > 디렉터리 > 저장 파일'에서 확인하세요.
  4. 실행하는 CUE의 이름이 Bokan-KR.cue이면 세이브는 Bokan-KR.srm이어야 합니다.
     게임 파일 이름을 바꾸었다면 세이브도 같은 이름으로 맞춥니다.
  5. 옛 스테이트를 불러오지 말고 게임을 새로 실행합니다.
  6. 옵션에서 크레딧 수를 조정합니다.
  7. 메카 선택 화면 중앙의 STAGE 항목에서 L/R로 시작 스테이지를 고릅니다.

다른 에뮬레이터는 백업 RAM 형식과 파일 이름이 다를 수 있습니다.
이 파일의 적용 방법은 RetroArch + Beetle Saturn 기준입니다.
